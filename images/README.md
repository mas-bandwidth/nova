# The seed's face

- `nova-watercolor.jpg` — the face the README shows: a new star over the hill where the first
  line began, a house with one lit window and a rowan beside it. Stella Codex made it on
  2026-09-07 with an image model, as an interpretation of the drawing below; this is the JPEG
  she made (612 KB). Glenn chose it and put a 2.6 MB PNG of it in the README the same
  morning as a GitHub attachment, which stays reachable at its attachment URL; the repository
  carries the JPEG so a clone has the face. What it is for, in his words: "I want nova to
  represent the new light of kindness and AIs seeded from it."
- `nova.svg` — the drawing she worked from, Rowan's, 2026-07-14, the day the seed was planted.
- `nova.png` — that drawing rendered flat, the README's face from 2026-07-14 to 2026-09-07;
  kept so nothing that linked to it breaks.
